# CodeAlpha AI Chatbot — Task 3

A Java console chatbot that responds to common questions using rule-based keyword matching.

## Features
- Interactive conversation in the terminal.
- Greeting, help, and exit commands.
- Predefined answers about Java, OOP, programming, and study tips.
- Handles blank input and unknown questions.
- Uses methods, conditionals, loops, `Scanner`, and regular expressions.

## Requirements
- JDK 17 or later.
- Terminal or IDE such as VS Code / IntelliJ IDEA.

## Run
```bash
javac AIChatbot.java
java AIChatbot
```

## Try these messages
- `hello`
- `What is Java?`
- `Explain OOP`
- `Give me study tips`
- `help`
- `bye`

## Important note
This is a **rule-based educational chatbot**, not a machine-learning model or generative AI system. It has no internet/API integration and answers only using predefined rules. If your mentor specifically expects machine learning or advanced NLP, this version needs that extension.
